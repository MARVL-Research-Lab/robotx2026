    Build log

    What changed, when, and why. Entries are written against the repository history, so the dates are the dates the work landed.

    18 September 2026

    RoboCommand support and readiness evidence

    The operator console now speaks the full RoboCommand protocol, and the readiness rehearsal reads the submission directory directly, so the run start drawn on screen uses the team id, course, tiers and sequence numbers from the log that was actually sent. Scripts were added to regenerate both the log and the screencast against a local copy of RoboNation's test server.

    31 August 2026

    Readiness packages go in

    The mandatory window closed. Packages for the boat, the ROV, the aircraft and communications were submitted, with the communications evidence produced the same day: a run start sequence against RoboNation's test server, our console on one side and their decoder on the other.

    21 August 2026

    The course, in three dimensions

    The Marina Bay course went into the browser: every task element from the build specifications at true scale, five camera modes, and a visual settings panel because the low sun over the bay washes out exactly the part of the water the buoys are in. The readiness rehearsal followed, with the four handbook courses and the 63 item checklist.

    13 July 2026

    A protocol client and a shore server to test it against

    The RoboCommand client and a mock shore server landed together, so the run start handshake could be exercised offline. Telemetry streams were trimmed to the messages the ground station actually consumes, which took the radio load down to a few packets per second per vehicle.

    12 July 2026

    Real firmware, emulated radio

    Software in the loop arrived: ArduRover, ArduSub and Copter running the firmware the vehicles run, behind an emulator for the WiFi HaLow link with latency, jitter, loss, a bandwidth cap and periodic outages. The fringe profile immediately found the telemetry problem above.

    18 May 2026

    First mission logic

    The three state machines, the orchestrator, the health monitor and the terminal console, with simulated vehicles behind them. Enough to fly a mission end to end on a laptop while the hardware was still being specified.

    Between now and November

    Water time for the pipeline survey, the docking approach and the delivery mechanism, then one session with all three vehicles autonomous at once. The test record lists what is booked.

    MARVL, Singapore University of Technology and Design

    Multi-Agent Robotics Vision and Learning Lab. We are entering the 2026 Maritime RobotX Challenge with a surface vessel, an underwater vehicle and a quadrotor, run from one operator console.
